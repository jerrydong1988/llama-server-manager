# v2.9.48 — 界面布局修复与官网自动更新

本版本集中修复长模型名称、引擎名称、路径和英文文字造成的界面溢出与按钮遮挡，并接通正式发版后的官网版本、下载入口和更新说明自动同步。

## 界面布局修复

- 修复创建实例时引擎选择框超出弹窗的问题，切换引擎弹窗中的长名称也能正确换行，关闭按钮保持可见。
- 实例列表按实际面板宽度调整布局，避免窄窗口下操作按钮被截断；长实例名称不再挤压状态标签。
- 路由表格保留必要列宽，空间不足时支持横向滚动，测试路由等操作保持可访问。
- 修复模型、引擎、集群和参数页面中长名称、路径、工作节点标签及命令预览的溢出，调整英文按钮和字段的排列。
- 修复顶部工具栏和使用指南宽表格在窄窗口下的显示问题，兼顾中英文及深浅主题。

## 官网发布同步

- 正式版本的安装包及更新清单发布成功后，自动核验 GitHub 与公开下载源的文件大小和 SHA-256，再同步官网版本资料。
- 官网通过独立 PR、检查和部署流程更新首页、下载页和更新说明，保留按版本补同步与部署恢复入口。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本及 Linux DEB 需要手动安装。Linux AppImage 和 Linux 应用内更新继续暂停。
- 未配置商业证书时，Windows 安装包标记为 unsigned，macOS 使用 ad-hoc 签名；应用内更新仍执行独立的 Tauri 签名验证。
- 建议在请求空闲时升级。现有实例、路由、API Key 和额度配置继续沿用。
