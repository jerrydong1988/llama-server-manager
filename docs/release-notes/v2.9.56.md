# v2.9.56 — 完善 Gufo 配置与检查点兼容性

本版本为 Gufo 增加思考预算、模型文件选择器和分组配置，修复检查点资格凭据的环境绑定，并同步 llama.cpp v0.9.0 的混合架构分类。

## Gufo 配置

- 增加独立的思考预算：−1 沿用不限预算，0 表示不生成思考，正整数限制思考 Token 数；最大输出 Token 数仍约束思考与最终回答的总长度。
- 主模型、视觉投影、MTP 模型和 DFlash2 草稿均可从模型仓库选择 GGUF 文件；隐藏后续分片，保留取消选择前的内容，并防止实例启动后继续写入选择结果。
- 按模型文件、服务与容量、推测解码、思考控制和缓存分组，采样设置支持折叠；优化长路径、窄窗口及中英文深浅主题布局。
- 旧配置默认保持不限思考预算，Gufo 与 llama.cpp 的预算字段独立；命令预览和启动使用同一参数生成与校验路径。

## 检查点与 llama.cpp 兼容

- 将 LLAMA_KV_ROWS_DISABLE 的存在与具体值纳入本地检查点资格身份；新增、删除或修改该变量都会使原资格凭据失效，空值和 0 也按实际环境区分。
- 旧版资格凭据无法证明此前的 KV rows 环境，需要重新进行隔离验证；不自动沿用缺少环境证据的批准结果。
- 同步 llama.cpp v0.9.0 稳定版基线，将 Clover MoE 与 Metis 1.6 纳入混合架构保守限制，并要求重新评估持久化检查点资格。
- 补充 b12061 原生检查点评估及验证工具；原生 API 测试证据不代表 Manager 已开放该构建的自动保存与恢复，具体支持仍由实际能力和资格验证决定。

## 安装与文档

- Windows x64 提供 EXE／MSI，macOS Apple Silicon 提供 DMG，Linux x64／ARM64 提供 DEB；Gufo 集成继续限于 Windows。
- README 增加东京官网镜像入口；升级沿用现有实例和数据，不自动替换模型或推理引擎。
