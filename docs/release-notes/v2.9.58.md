# v2.9.58 — llama.cpp v1.0.0 兼容与依赖安全维护

本维护版适配 llama.cpp v1.0.0 的稳定参数定义，增加按引擎能力校验的 FP8 KV 配置，并更新内置 SQLite 及运行时依赖，保留现有实例配置和数据。

## llama.cpp v1.0.0 兼容

- 稳定参数基线由 261 项更新为 266 项，完成新增 6 个参数、移除 1 个参数及相关说明的适配审查。
- 在主模型和草稿模型的 K/V 缓存选项中加入 f8_e4m3；只有所选引擎明确报告支持时才允许使用，CLI/MCP 启动请求也执行相同校验。
- 通过经引擎能力校验的自定义参数支持 MoE CPU 缓存分担及 TTS 语言、音色；额外 GGUF 分片和网络访问放宽选项保留为手动命令，不自动更改鉴权策略。
- 根据所选引擎检测结果处理已移除的 --defrag-thold／-dt，保留旧引擎兼容性，不静默改写已保存命令。
- 更新推理保留、同源 CORS 和 llama.cpp Web UI MCP 代理说明，补充 Kimi K3.1 检查点限制回归。

## 依赖安全维护

- 将内置 SQLite 更新至 3.54.1，修复 RUSTSEC-2026-0459，并验证 WAL 事务隔离、回滚、持久化重开和数据完整性。
- 更新 rustix 至 1.1.6、Tokio 至 1.53.3，修复对应安全性公告；用 async-executor 1.14.1 替换已撤回版本。
- 重新核对 GLib 本地安全补丁、上游修复与 Linux 优化回归；继续保留唯一的受控例外，并将下次复核日期设为 2026-12-15，不增加审计忽略项。
- Tauri 依赖链中的三项 D-Bus 组件维护状态提示仍保持可见，后续随上游迁移处理。

## 构建与验证

- 通过 Cargo 编译产物信息定位测试宏库，兼容 Rust 1.100 的构建目录变化；源码构建要求 Rust 1.89 或更新版本。
- 修正跨平台 lint 和 Linux 测试程序路径处理，保留符号链接、授权目录及运行时安全校验。
- 保留 CLI/MCP 显式启动、连接时不自动拉起桌面程序的行为，并继续执行运行时生命周期与管理接口回归。

## 安装与使用

- 延续现有实例、模型、引擎、缓存和路由数据；更新管理器不会自动升级已安装的 llama.cpp 引擎。
- FP8、MoE 分担和 TTS 的参数适配不代表所有 GPU 后端与模型均已通过实际推理验证，具体能力仍以所选引擎及模型为准。
- Windows 和 macOS 沿用现有更新渠道；Linux 继续提供 x64／ARM64 DEB 安装包，AppImage 与 Linux 应用内更新仍暂停。
