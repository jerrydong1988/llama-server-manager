# v2.9.59 — 推理监控、命令预览与运行时恢复修复

本版让性能监控区分推理活动、空闲与采样缺失，修复 Gufo 和 llama.cpp 的实例命令预览，并解决 Windows 后台路由在并发冷启动和端口恢复时暴露的两项问题。

## 性能监控与大屏

- 性能监控在同一时间轴上用短柱显示 Prefill、用折线显示 Decode，保留孤立样本并对齐零刻度。活动带区分并行阶段、确认空闲和缺少观测，不把遥测缺口画成吞吐跌零。
- 大屏优先显示实例健康检查和当前生成吞吐，趋势按 15 秒窗口汇总连续活跃样本。只有部分实例上报时显示覆盖数与已上报小计，不冒充完整吞吐。

## Gufo 与命令预览

- 根据所选 Gufo 引擎的帮助输出判断草稿长度是否由模型决定。新版使用只读提示，预览、启动及后台恢复不再传入已忽略的 --draft-tokens；旧引擎仍可编辑，原有配置值保留。
- 实例页生成命令时，能力缓存缺失或过期会自动重新探测所选引擎一次。修复 Gufo 直接报错，以及 llama.cpp 将只有模型、地址和端口的保守命令误作完整预览的问题。探测仍不完整时明确提示，不强行写入继承的默认值。

## b12469 检查点本地验证

- 为特定 Windows HIP/ROCm b12469 构建与 Qwen3.6-35B-A3B UD-Q8_K_XL 内置 draft-mtp 增加本地验证入口。每槽 8192 上下文；1 或 2 槽可验证全 f16 或全 q8_0，4 槽仅 f16。4 槽 q8_0 仍不支持，不按版本号放行其他构建或模型。
- 新版验证在所有槽填充后保存，退出旧进程并在新进程并发恢复。使用检查点仍需与机器、驱动和配置匹配的本地验证凭据；旧凭据需要重验，不删除已保存的数据。

## 后台路由与配额

- 修复并发首请求争用 SQLite 配额账本初始化而返回 503 的问题。已就绪的账本不再重复切换 WAL 或创建表；配额检查失败仍不会转发请求。
- 修复端口释放、代理重新绑定成功后，状态仍保留旧端口占用错误的问题。发布运行状态时一并清除对应的路由错误，不覆盖无关运行时错误。
