# v2.9.50 — 应用内更新与后台服务交接修复

本版本修复应用内更新完成后自动打开程序时，旧后台服务尚未退出导致连接警告的问题，完善更新失败后的恢复与重试，并及时清除已恢复的后台连接警告。

## 应用内更新

- 更新包下载并通过签名验证后，再等待正在执行的后台操作完成并准备安装，避免下载失败或网络缓慢时提前中断后台服务。
- 安装前通过已认证的连接正常停止后台服务，保留实例预期运行状态与配置，并等待系统文件锁真正释放；安装交接期间阻止重复启动后台服务。
- 后台服务未能安全退出时停止安装；准备或安装失败后解除更新暂停，恢复后台连接，重试可复用已经验证的更新包。

## 启动与警告

- 程序启动时为旧后台服务退出提供有界等待，并在重试中重新检查文件锁状态，减少更新重启期间的连接冲突。
- 后台连接恢复后自动清除对应的连接警告，继续保留实例运行错误及尚未恢复的故障信息。
- 保留后台通信身份校验与更新包签名验证，不通过强制终止进程或删除锁文件完成更新交接。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本及 Linux DEB 需要手动安装。
- 本次更新交接修复在新版本运行后生效；从旧版升级到本版的安装准备阶段仍由旧版执行。若升级后出现连接警告，待后台连接恢复后会自动清除。
- 建议在请求空闲、下载任务完成后升级，现有实例、路由、API Key 和额度配置继续沿用。
