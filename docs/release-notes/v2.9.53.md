# v2.9.53 — 统一管理接口、检查点恢复与推理监控

本版本新增 CLI／MCP 管理接口和共享后台任务，扩展已验证配置下的检查点保存与恢复，并完善 Prefill／Decode 监控、异常恢复和跨客户端状态同步。

## CLI、MCP 与后台任务

- 新增管理命令行与 MCP 接口，可查询和管理实例、引擎、模型目录、下载、路由、检查点及存储；支持独立数据目录、权限限制、配置冲突检测和幂等请求。
- GUI、CLI 与 MCP 共用任务状态和历史记录；支持取消尚未执行的任务、查看执行结果，以及清理已结束的任务记录。
- 慢速引擎探测和下载准备按资源调度，减少对无关实例启停及界面操作的阻塞。
- 修复任务日志写入失败后未执行任务停留在运行中、提交失败丢失旧历史及幂等键的问题；未开始的操作明确报告失败，恢复存储后可继续管理任务。
- 修复旧配置中的相对目录删除显示成功但未生效，以及较晚返回的旧列表覆盖引擎、模型和 Worker 最新状态的问题。

## 检查点与缓存生命周期

- 增加空闲时自动保存和保留较长提示词缓存的策略，并扩展经过验证的四槽检查点保存与恢复。
- 增加本地 b11849、b11913 及限定 Gemma 4 MTP 配置的验收范围；持久化能力按引擎运行文件、模型身份和启动配置校验，仅对匹配的已验证组合开放。
- 恢复失败时保持路由关闭，替换受影响的进程后再走冷启动；保留原有自动恢复策略，避免把部分恢复误报为完整成功。
- Windows 引擎使用独立隐藏控制台管理退出；托管动态 n-gram 缓存采用私有工作文件、结构校验和两代回滚，完整刷盘仍不作为已验证保证。

## 推理监控与界面

- 分开显示 Prefill 与 Decode 的近期吞吐、任务阶段和历史趋势，区分实时值、采样中、部分覆盖、过期及不可用状态。
- 改进紧凑桌面布局、配置页面响应速度和后台任务面板，保留加载期间产生的未保存编辑。
- 更新 llama.cpp v0.7.0 参数兼容性基线，并保留对上游开发分支变化的独立跟踪。

## 可靠性与维护

- 改善配额数据库首次并发初始化，保留额度预留和结算的原子性；数据库异常时拒绝放行。
- 加强依赖供应链检查、安全补丁校验及跨平台构建门禁；新增任务日志故障、旧目录配置和异步刷新顺序回归测试。
- 移除未使用的 Updater ZIP 解压依赖，并继续核对更新载荷与签名清单的一致性。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本及 Linux DEB 需要手动安装。
- Linux AppImage 仍处于候选验证阶段，不列入本次正式安装包；Linux 管理宿主仍依赖桌面会话。
- 升级继续沿用已有实例、路由、API Key 和额度配置；检查点验收结果不代表未列入范围的模型、引擎或后端已获得同等验证。
