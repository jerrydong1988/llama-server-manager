# v2.9.60 — 统一桌面界面、路由密钥管理与性能监控

模型仓库、实例列表、参数配置和路由页采用统一的明暗主题。调用方较多时，可以在独立的 API Key 页管理单个密钥。性能监控和大屏增加了五分钟趋势，并在驱动提供读数时显示 GPU 温度与功率。

## 实例、模型与配置

- 实例名称下方显示运行状态，整行底色标记当前操作的实例。侧栏的下载管理和实例管理分别显示正在传输的文件数和运行中的实例数。
- 从参数配置返回时，列表会恢复所选实例、搜索与筛选，并将选中行滚动到可见位置。实例端口等变更导致筛选不再匹配时，自动清除冲突的条件。
- 创建实例、llama.cpp 和 Gufo 的文件选择窗口共用仓库目录树，可按名称或量化搜索，并查看层级、文件类型和大小。配置工具栏统一了控件尺寸，总览底部卡片对齐。

## 实例路由与 API Key

- 路由页分为路由与实例、API Key、使用统计、路由设置。点击路由表某一行的对外模型名即可更换绑定实例、调整优先级或移除该条规则。
- API Key 支持按调用方搜索、按状态筛选和分页，每页八项。选择一项即可编辑权限、请求频率、并发、预算和额度。单个 Key 的保存与删除独立提交，窄窗口编辑后可回到原列表位置。

## 性能监控与大屏

- 实时概览集中显示最近五分钟的吞吐、显存、GPU 温度和功率。点击读数可查看趋势。大屏汇总实例健康和生成或向量吞吐，排队、下载、日志与告警可在运行详情中展开。
- Prefill 可按已完成请求、实例实时和任务实时查看。短请求完成后也能看到预填充速度。llama.cpp 的实例速率使用引擎累计计算时间，Gufo 使用处理 Token 增量和两次采样之间的实际时间。
- 已有遥测数据库在首次打开时从结构版本 9 升至 10，保留历史采样与请求记录。旧记录没有采集的预填充时间继续留空。

## 启动、恢复与依赖

- 桌面、CLI 和 MCP 共用引擎选择和启动参数构造。后台恢复按进程身份和状态快照顺序重新连接日志，避免迟到的停止事件覆盖新进程。启动期间所做的配置修改保留给下一次启动。
- Rust URL 解析依赖升级到 2.5.9，修复 RUSTSEC-2026-0592 公告所述的进程栈溢出问题。
- Tauri 使用的 cookie 依赖升级到 0.18.3，纳入 RUSTSEC-2026-0594 所列的私有 Cookie 加密修复。
