# v2.9.46 — 检查点恢复、存储维护与参数兼容更新

本版本新增默认关闭的实验性 KV / Prefill 缓存检查点和存储维护页面，并完善实例生命周期、路由、配置保存和日志操作。

## KV / Prefill 缓存检查点

- 支持在受控停止前保存 slot 0 的提示词/KV 状态，并在再次启动、代理开放路由前恢复。
- 支持完整 GGUF 分片集；根据引擎实际报告的能力判断 n-gram、MTP、DFlash 和 DSpark 等推测组合的检查点资格。涉及 draft context 的恢复仍要求引擎明确支持 context checkpoint 持久化。
- 对模型、草稿模型、引擎及相关配置进行指纹核对，并验证检查点文件大小、SHA-256 和恢复结果。
- 恢复已开始后如发生错误，保持路由关闭，在新进程中冷启动，避免继续使用不完整状态。
- 状态页区分文件验证结果与实际请求缓存指标；检查点清理、容量限制和失败文件隔离得到完善。
- 已知不满足状态持久化要求的 hybrid/recurrent 模型安全回退冷启动；检查点功能不等同于通用多前缀磁盘缓存。

## 存储维护与文件管理

- 新增存储维护页面，分类查看和清理应用临时文件、隔离文件、更新暂存及崩溃记录，并支持预约下次启动清理 WebView 缓存。
- 外部缓存和用户指定路径以清单方式展示，清理范围限制在受管目录和明确的文件类别。
- 限制实例日志与遥测保留量，完善检查点、下载、模型分片和附属文件的生命周期，避免跨实例误清理。

## 参数兼容性

- 官方稳定参数基线对齐 llama.cpp v0.4.0，包含 257 个参数条目。
- 推测解码类型改为根据引擎探测结果提供的下拉多选，并统一参数顺序。
- 后端采样与推测解码的组合提示改为判断引擎版本，避免对已经支持的版本继续显示必然回退警告；未知版本保留能力未确认提示。
- 重新评估统一 KV、上下文、自动内存适配、采样器别名与自定义参数覆盖，补充张量拆分和量化 V 缓存对 Flash Attention 的约束提示。
- 允许通过已验证的 Lazy Mode 参数组合使用符合条件的检查点。

## 可靠性修复

- Windows 停止实例时隐藏检查点目录权限检查命令，消除短暂闪出的黑色命令行窗口。
- 日志虚拟滚动保留文本选择范围，改善跨行拖选和复制。
- 配置页切换后保留未保存草稿，并在保存时合并其它页面已持久化的设置。
- 修复路由响应等待、请求容量释放、并发唤醒及实例退出状态处理。
- 补齐运行时生命周期测试的前台进程登记，覆盖超时边界，避免 CI 中命名管道偶发消失。

## 安装与兼容性

- Windows x64 提供 EXE / MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13。
- Linux x64 / ARM64 继续提供 DEB；AppImage 和 Linux 应用内更新仍暂停。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本需要手动安装一次新版本。
- 无商业证书时，Windows 安装包标记为 unsigned，macOS 使用 ad-hoc 签名；应用内更新仍执行独立的 Tauri 签名验证。
- 检查点默认关闭且仍为实验性功能；支持与收益取决于引擎、模型和实际请求，不能仅凭恢复成功判断前缀已复用。
