# v2.9.52 — 命令预览改进与紧凑布局

本版本重新整理实例管理中的命令预览，按用途清晰展示启动参数，并通过紧凑布局和分组折叠减少长参数列表占用的纵向空间。

## 命令预览

- 按模型、上下文与缓存、性能与内存、采样、推测解码、网络与服务等用途分组展示参数，更方便核对实际启动配置。
- 宽窗口采用双列布局，模型路径保留整行空间；窄窗口自动切换为单列，长路径与参数值可换行查看。
- 支持单独折叠分组、全部展开与全部收起，并显示参数数量；限制弹窗高度，滚动查看参数时仍可使用标题栏和底部操作按钮。
- 完整终端命令可单独展开查看，复制完整命令继续保留安全的参数转义；敏感参数默认隐藏，直接启动继续使用应用内启动流程。
- 完善中文、英文、明暗主题与键盘操作体验。

## 验证与维护

- 增加命令预览的响应式布局、分组折叠、敏感参数、复制与键盘交互回归覆盖。
- 改进检查点恢复及 Windows 后台通信身份校验的测试同步方式，减少因 CI 调度和进程启动速度差异导致的偶发测试失败。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本及 Linux DEB 需要手动安装。
- 升级后现有实例、路由、API Key 和额度配置继续沿用。
