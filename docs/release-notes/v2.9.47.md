# v2.9.47 — 路由用量统计、请求诊断与 Key 额度管理

本版本完成实例路由的使用统计、图表、性能分析和 API Key 使用管理，并修复 Windows 路由重启端口占用、部分客户端启用强制额度后无法调用等问题。

## 用量统计与请求诊断

- 按 API Key、模型、实例和接口统计请求、输入／输出 Token、缓存用量及用量完整性，提供趋势图、结果分布、用量排行与 CSV 导出。
- 请求历史支持时间、结果、错误类型及请求 ID 检索，使用稳定分页查看更早记录；详情区分请求拒绝、失败、取消和中断。
- 上下文超限时展示输入、预留输出、模型窗口及超出量，便于调整客户端的历史长度和输出上限。
- 增加首个有效输出、排队与总耗时的 P50／P95、小时趋势和慢请求分析；重新安排总览页面与“当前用量与并发”区域。
- 统计保存请求元数据和引擎报告的计数，不保存提示词、回答正文或密钥。明细保留 90 天，日汇总保留 365 天；未知用量明确标记，不作为实测零值。

## API Key 使用管理

- 支持日／月 Token 软预算、每 Key 并发限制及可选的公平排队；软预算只提醒，不拦截请求。
- 新增默认关闭的日／月强制 Token 额度，转发前持久化预留，完整响应后结算；重启服务或清除使用统计均不会重置额度。
- 兼容 Octop 等客户端省略输出上限的请求：启用强制额度时使用该 Key 的默认输出上限（初始值 32,768），并按模型剩余上下文缩小默认值；兼容常见输出参数别名。
- 强制额度暂只支持单次生成／单个补全提示词。无法可靠计数的请求会返回具体原因；已转发但取消、中断或用量未知的请求保守保留额度占用。
- 自动分批清理超过 365 天的已结束额度请求和无引用历史周期，保留待结算预留，并展示账本占用与可复用空间。

## 可靠性与参数兼容

- 修复 Windows 模型子进程继承路由监听句柄导致停止后端口仍被占用的问题，停止后可正常再次启动。
- 修复全部已配置 API Key 被禁用时意外放开匿名访问的问题；只有明确清空 Key 列表才启用本机匿名模式。
- 更新后台运行时能力校验，避免新版界面复用仍存在旧问题的后台进程。
- 官方稳定参数基线对齐 llama.cpp v0.4.1，共 255 个条目；更新加载模式、JSONL 日志和相关参数提示，并保留经过引擎能力探测的旧参数兼容。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Linux AppImage 和 Linux 应用内更新继续暂停。Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新，更早版本需要手动安装。
- 未配置商业证书时，Windows 安装包标记为 unsigned，macOS 使用 ad-hoc 签名；应用内更新始终执行独立的 Tauri 签名验证。
- 升级时会更新后台运行时，运行中的模型可能重新加载，建议在请求空闲时升级。现有实例、路由与 Key 配置沿用，强制额度不会自动开启。
- 用量统计用于使用分析与容量管理，不是正式计费凭据；引擎未报告的用量不会补写为估算值。
