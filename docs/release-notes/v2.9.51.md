# v2.9.51 — 检查点启动状态与运行警告修复

本版本修复应用内更新后首次打开程序时，检查点状态过早读取可能产生运行警告，并在后台服务恢复后仍残留的问题。

## 启动状态恢复

- 检查点状态读取统一等待后台服务完成启动、版本协商与身份校验，避免更新重启期间绕过启动协调直接连接尚未就绪的服务。
- 后台服务返回完整检查点状态后，自动清除对应的历史初始化警告，继续保留实例运行错误及尚未恢复的连接故障。
- 忽略已经被新状态替代的初始化响应，避免迟到的失败重新显示警告，或迟到的旧数据覆盖最新检查点状态。
- 更新交接期间继续阻止启动后台服务，保留通信身份校验和更新包签名验证。

## 安装与升级

- Windows x64 提供 EXE／MSI；macOS Apple Silicon 提供 DMG，最低要求 macOS 13；Linux x64／ARM64 提供 DEB。
- Windows 与 macOS 的 v2.9.36 及以后版本支持应用内更新；更早版本及 Linux DEB 需要手动安装。
- 升级后现有实例、路由、API Key 和额度配置继续沿用。
