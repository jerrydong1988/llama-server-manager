# Agent 管理接口架构

实现起点：`82abee4`，初始探索分支：`codex/agent-management-exploration`，版本 2.9.52。
实现通过 PR 流程集成；PR 与 master 的 CI 都提供人工测试包，不自动创建正式版本。
测试包的确切提交、平台和构建时间以包内 `BUILD.json` 为准。

## 目标与交付边界

让桌面界面、命令行和 MCP 操作同一份模型、引擎、下载、实例、集群及路由状态。
所有操作复用 Rust 的校验和执行路径；CLI 和 MCP 不自行修改 instances.json，不执行拼接的 shell 命令。
探索版首先提供本机、当前操作系统账户内的管理。远程网络管理不开放。

管理宿主复用桌面应用的 AppState 和现有命令实现，通过私有本地 IPC 接受请求。
CLI 可启动隐藏的管理宿主；关闭或隐藏窗口不会终止管理任务。显式退出应用会停止管理宿主，
独立推理运行时继续遵循现有后台策略。客户端退出不取消已提交任务。
Linux 的管理宿主仍需要桌面会话；真正无 DISPLAY 的 Linux daemon 需要将 Tauri AppHandle
进一步抽象为事件与状态服务，属于明确的后续平台边界，不能宣称本探索版已经支持。

## GUI 后台任务

右上角 **任务中心（Ctrl+K）→ 后台任务** 可查看管理接口的任务记录。GUI 通过 Tauri
调用管理宿主的同一个任务列表、详情和取消实现，与 `lsm tasks list/get/cancel` 及
MCP `tasks_list/get/cancel` 共用任务 ID、状态、结果、错误和持久化文件。没有第二套 GUI 任务库。
现有直接 GUI 资源操作不会被补写成虚构的管理任务；这里展示提交到管理宿主的操作。

- 按操作名称或任务 ID 搜索，按排队、执行中、成功、失败、取消、中断筛选；最多保留 200 条。
  列表返回完整的保留范围，避免较早排队的任务被“最近 100 条”截断。
- 选中任务查看创建/更新时间、执行结果 JSON、错误码、原因和是否可重试。过大的结果快照
  会明确提示查询资源，不把缺失结果显示为零值或成功数据。
- 只取消排队任务（包括网络准备阶段）。运行中的操作不在事务中途强杀，应进入对应资源
  执行停止/暂停。取消和开始执行共用后端锁；若任务已开始或完成，显示实际状态。
- 任务变更事件驱动刷新，并在可见时每 3 秒补查；关闭面板停止订阅和轮询。切回窗口、
  重新打开或重启应用后会重新读取持久化记录。刷新失败会保留并标注旧列表。
- 启动命令成功不等于模型就绪，添加下载命令成功不等于文件传输完成。模型健康和下载进度
  继续在对应页面查看。宿主异常退出留下的任务标记为中断，重试前必须核对资源状态。

回归包括成功/失败结果、取消竞争、外部状态刷新、错误恢复、旧详情响应、双语、明暗主题和
窄窗口。实机交叉验证需从 CLI/MCP 提交任务、在 GUI 查看并取消，再以同一任务 ID
从 CLI/MCP 读取终态，并重启管理宿主验证记录恢复。

## 架构与职责

1. **管理契约**：版本化操作目录、输入 JSON Schema、输出信封、错误码、只读/修改/删除标记。
2. **本地传输**：Windows 命名管道、Unix socket；独立于推理控制令牌；账户/端点校验、帧大小和超时限制。
3. **管理宿主**：认证、参数校验、序列化配置修改、任务登记、执行、审计及 UI 变更通知。
4. **领域适配**：调用现有扫描、下载、能力探测、启动校验、运行时、集群及路由实现。
5. **CLI**：独立控制台入口，帮助、操作发现、JSON 参数文件、JSON 输出、退出码、任务等待、服务启动。
6. **MCP**：stdio 工具、结构化结果、能力发现；默认只读，按启动配置开放修改、删除、远程集群操作。
7. **GUI 同步**：配置版本与变更通知；外部修改不能被陈旧前端快照覆盖。界面保持现有操作方式。

## 功能覆盖矩阵

| 领域 | 探索版必须覆盖 | 边界与校验 |
| --- | --- | --- |
| 服务 | 状态、能力目录、隐藏启动、窗口显示 | 不自动修改登录启动项；区分管理宿主与推理运行时 |
| 路径 | 列举授权、添加/撤销模型/引擎/下载目录 | 规范化路径；已有符号链接/目录联接校验；MCP 不自授目录权限 |
| 模型 | 列表、刷新、元信息、删除预览、删除 | 复用分片模型和受管理文件安全检查 |
| 引擎 | 列表、刷新、目录导入/移除、默认选择、重命名、单个/批量能力探测、打开目录、引用检查、库存移除预览/执行 | 使用中或被配置引用的引擎拒绝移除；探测结果与二进制身份关联；移除库存或目录均不删除文件，再次扫描可重新发现 |
| 引擎分发 | 现有本地引擎完整管理 | 仓库目前无引擎包下载安装器；不把模型下载冒充引擎安装。后续安装器需要来源、校验、解包、暂存、探测、原子切换与回退 |
| 下载 | 仓库浏览、入队、快照、暂停、恢复、取消、重试、清理记录、并发数、带宽、低优先级策略 | 复用队列所有权、续传和路径边界；退出客户端不取消；重启宿主按恢复策略处理 |
| 实例 | 默认配置、列表、读取、创建、克隆、更新、重命名、删除、命令预览、参数校验、启停、健康 | 按对象修改；版本冲突返回明确错误；默认引擎解析；运行中删除拒绝；停止与删除分离 |
| 参数 | 配置字段/默认值、引擎实际支持选项、生成命令 | 现有参数和手动端口兼容规则复用；不对未知字段静默成功 |
| 集群 | Worker 列表、TCP/mDNS 发现、测试、添加、批准、移除、本地 RPC 启停、SSH RPC 与隧道 | 集群操作独立授权；trust=true 代替交互信任弹窗；本地/SSH 启动自动登记、登记失败回收；SSH 凭据不进入审计 |
| 路由 | 配置读取、校验/保存、状态、目标、路由测试、启停/重启 | 返回值隐藏密钥；配置修改保留未修改密钥；并发修改冲突检查 |
| 观测 | 系统健康、运行时、监控、日志、任务与审计查询 | Prefill/Decode 的实时/阶段平均/不可用字段原样保留；任务摘要数量与输出大小限制 |

### 非集群接口扩展（2026-10-19）

新增 44 项操作，覆盖现有非集群后端的管理功能；具体参数以 `lsm help` 和
`service.capabilities` 返回的 schema 为准。CLI 使用空格分隔，MCP 将点替换为下划线。

| 领域 | 新增操作 | 语义 |
| --- | --- | --- |
| 窗口与后台 | `service.hide`、`runtime.status/clear_error/detach/stop` | 隐藏不退出；detach 完成接管和任务持久化后退出宿主；stop 停止后台实例与路由 |
| 模型与下载 | `models.open_folder`、`downloads.local_files/delete_file` | 本地文件检查仅限授权根；删除必须证明下载所有权，并再次检查整个模型分片组的引用 |
| 实例诊断 | `instances.clear_log/slots/metrics/test_connection/resources/open_browser` | 复用当前运行实例的健康、端点及资源数据；日志清除同步已打开窗口 |
| 检查点 | `checkpoints.list/status/eligibility/clear` | 资格、文件恢复和请求缓存复用是不同状态；运行中不能清除；不放宽架构兼容限制 |
| 参数模板 | `presets.list/preview/apply` | GUI 与接口使用同一份内置模板；preview 不落盘；apply 需最新 revision，仅保存、不重启 |
| 路由用量 | `usage.summary/requests/performance/budgets/export/clear` | 逐请求、汇总、延迟、预算/硬额度及 CSV；清理历史不重置额度账本，未知 token 不伪装成零 |
| 监控历史 | `monitoring.series`、`telemetry.overview/sessions/samples/detail/analysis/diagnostics/requests/prune/optimize` | 复用实时与持久化遥测；有界查询；清理与优化遵守原保护规则 |
| 存储维护 | `storage.inventory/external/cleanup/webview_cleanup` | 仅已知存储组可清理；WebView 缓存按下次启动计划处理；外部文件只报告引用 |
| 系统 | `system.port/autostart/set_autostart` | 自启动设置仅本机所有者 CLI 可改，保留独立 data-dir，GUI 接收变更通知 |

删除、清理与遥测优化需要 MCP `--allow-delete`；后台交接需要 `--allow-write`。
路径自授权、宿主强制退出和登录启动项修改仍不开放给 MCP。
窗口布局、主题、语言、文件选择器等界面偏好继续由 GUI 管理；安装正式更新需 GUI 的安装器流程，
裸可执行文件探索包不自动安装正式版。项目没有引擎包下载安装器，不声明这项能力已实现。

实测矩阵、复现命令和已知边界见 [非集群交叉验证](agent-management-noncluster-validation.md)。

## 一致性和执行语义

- 修改任务按资源或领域调度；按对象修改和 GUI 快照保存共享配置提交锁，网络准备在提交锁外执行。
- 基于配置内容的 revision 用于陈旧快照检测；冲突不重试覆盖，调用方先读取新配置。
- 请求信封返回 id；修改任务返回 task_id，支持后续查询和等待。
- 显式幂等键用于副作用请求；相同键不同参数拒绝；持久化任务记录，崩溃后标记 interrupted，不能伪报成功。
- 成功返回是操作已完成/已入队的具体含义；启动进程成功与健康 ready 分开。
- 任务保留 200 条，摘要查询返回 100 条；单条结果限 128 KiB。幂等窗口与保留窗口一致，输入参数不落任务日志，输出敏感字段脱敏。
- `tasks.cancel` 取消尚未开始副作用的 queued 任务；running 任务返回 `TASK_RUNNING`，应使用资源自身的 stop/pause。重复取消保留已有终态，取消记录在宿主重启后保留。
- 删除预览给出文件范围和引用；执行再次校验，不依赖过期预览。
- 配置更改发送事件，前端重新加载；前端保存携带原版本，防止 GUI 旧快照覆盖外部修改。

## 安全与兼容

仅当前账户本机连接，管理凭据和推理 API Key 隔离。MCP 权限在适配层执行，工具目录仅展示
允许的操作。CLI 作为账户所有者管理入口具备完整权限。参数为结构化数据，不能把任意命令
执行器作为管理工具。日志、路由、实例配置输出脱敏；敏感字段更新采用明确 patch。

MCP 使用标准 stdio JSON-RPC，stdout 仅输出协议，诊断写 stderr；固定并说明支持的协议版本。
不要求客户端支持可选 Tasks 扩展，任务查询作为普通工具提供。CLI 支持无 MCP 的 Harness。
服务端和客户端版本不兼容时明确拒绝，不能将旧二进制静默当作新服务。

## 验证计划

1. 契约：所有操作可发现、输入 schema 和实现一致、未知字段拒绝、错误可机器判断、敏感值脱敏。
2. 传输：认证失败、错误版本、超大/不完整帧、超时、连接断开、多客户端、重复请求。
3. 引擎：新增目录、刷新、重命名、默认引擎、探测、替换二进制后缓存失效、被引用/运行中删除保护、目录移除不删文件。
4. 实例：创建/修改/克隆/删除、缺失模型/引擎、端口冲突、手动端口、参数兼容、启停幂等、健康状态。
5. 一致性：GUI 与 CLI 同时修改、两个 CLI 同时更新、保存过程失败、宿主重启、旧版本客户端。
6. 下载：排队/进度/暂停/恢复/取消/重试/限速、客户端退出、宿主重启、部分文件保护。
7. 集群与路由：节点校验、SSH 配置错误、路由探测、热变更限制、密钥脱敏和保留。
8. MCP：initialize、tools/list、tools/call、只读权限、结构化错误、长任务查询、EOF 退出。
9. 全量门禁：check:release、生产构建、Rust 测试与严格 Clippy、运行时回归、跨平台 CI。
10. 人工交付：分支提交、测试包、SHA256、CLI/MCP 接入示例、逐项验收清单和实际验证范围。

## 回退

探索版使用明确指定的数据目录测试。用户现有模型和引擎文件不搬移。
配置格式新增字段保持向后兼容；新管理数据存放于独立 management 目录。
停止探索版宿主后可启动 master 测试包；不得同时运行两个版本写同一数据目录。

## 后续演进条件

1. **真正无图形依赖的宿主**：把 AppHandle 中的事件、路径选择和授权对话框抽象为服务接口，再将领域逻辑迁移到共享库；CLI/MCP 契约保持稳定，逐个迁移，避免双写配置。
2. **引擎安装器**：平台/后端/架构清单、可信下载地址及校验和、归档路径保护、暂存探测、原子安装、版本回退、使用中文件锁。应形成独立领域，不能直接开放任意 shell 安装命令。
3. **远程管理**：另行设计认证、权限、TLS、请求审计和远程目录语义；本机 IPC 不直接绑定公网。
4. **更大规模任务**：在现有按资源调度和 queued 任务取消基础上，扩展分页、任务进度和长期幂等账本。GUI 当前没有管理任务列表；任务记录通过 CLI/MCP 查询，界面显示资源操作结果。
5. **正式版本验收**：PR 合并后继续使用 master CI 测试包，收集各平台桌面、真实远端集群和长下载反馈；正式版本的打标签与发布另行执行。
